# Commit message cheat sheet

    <type>: <imperative summary, <= 50 chars>

    <blank line>
    Why the change was made (wrap at ~72 chars).
    Closes #42

Types: feat, fix, docs, style, refactor, test, chore, ci, build.

Good:  `feat: add subtract function`
Bad:   `changes`, `fixed stuff`, `asdf`
